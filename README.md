# 语文课堂提问系统 · 部署上线手册

一个纯静态的语文随堂提问网站：按课文组织题库，**老师自己上传题目、在网页里直接增删改题目**，课堂上可以**随机点名提问**（自动给每位学生分不同的题），也可以让学生自己逐题练习、即时判分、错题回顾。  
零依赖（不需要 Node、不需要后端、不需要数据库），把文件夹原样丢到任何静态托管上就能跑。

> **拿到压缩包的老师看这里**：解压后双击 <b>使用教程.html</b>（图文版，含录题、上课、备份全流程），或直接双击 <b>index.html</b> 立即开始使用——已内置《观潮》《走月亮》示例，无需安装、无需联网。本文档面向部署与进阶维护。

**两种维护题库的方式，随时可换：**

1. **Excel 文件**：在 Excel 里编辑 `.xlsx` → 上传到网站 → 页面立即生效；也可一键把当前题库导出为 `.xlsx` 存档
2. **网页直接编辑**：在「题库管理」里逐题增删改、调整顺序 → 改完立即生效，无需上传任何文件

> **部署提示**：`tests/` 目录只用于本地测试，**上传到服务器时可以不带**，不影响网站运行。

**关于两份示例的关系**（容易混淆，说明一下）：

- 网站打开时加载的是 `assets/js/data.js` 里的 `DEMO_BANK`，目前内置 **2 篇课文 12 道题**（《观潮》8 题 + 《走月亮》4 题）
- `sample/` 目录下的 CSV 是**同样内容的独立文件**，专门用来在「题库管理」里练习导入流程。网站不会自动去读它——纯静态站点读取不了磁盘上的其他文件
- 如果你想修改内置示例：改 `data.js` 里的 `DEMO_BANK` 之后，记得把文件末尾的 `DEMO_SEED_VERSION` 加 1。这样已经打开过网站的浏览器会自动补上新增的课文，但**绝不会动老师自己录入的题目**

**部署时整个文件夹的内容都要上传**，`assets/` 的目录层级不能变，否则页面会白屏。

## 三、上传题目：支持 .xlsx / CSV / 文本 / JSON

进入网站「题库管理」页，可拖拽文件、也可直接粘贴文本，系统会**自动识别格式**。

### 格式一：Excel 文件（.xlsx，推荐）

**直接上传 `.xlsx`，不用再另存为 CSV。** 支持两种排布方式：

- **单表多课**：一张工作表里用「课文」列区分课文（同 CSV 表头）
- **多表分课**：每个工作表一张课文，**工作表名 = 课文名**，表内首行为列名

网站内提供「下载 Excel 模板」按钮，模板里自带填写说明工作表。

**导出存档**：「题库管理 → 导出 Excel 题库」会把当前网页里的题库（含你在网页上改过的所有内容）导出为带格式的 `.xlsx`，可直接在 Excel 里修改后重新上传，形成闭环。

| 课文 | 年级    | 题型  | 题干            | 选项A  | 选项B  | 选项C   | 选项D  | 答案       | 解析     |
| -- | ----- | --- | ------------- | ---- | ---- | ----- | ---- | -------- | ------ |
| 观潮 | 四年级上册 | 选择题 | 钱塘江大潮自古以来被称为？ | 天下奇观 | 世界奇景 | 天下第一潮 | 人间胜景 | A        | 开篇总起句  |
| 观潮 | 四年级上册 | 判断题 | 潮来前江面上很平静。    |      |      |       |      | 正确       | 与潮来时对比 |
| 观潮 | 四年级上册 | 填空题 | 形成一堵两丈多高的（　）。 |      |      |       |      | 水墙       | 以水墙喻浪  |
| 观潮 | 四年级上册 | 简答题 | 作者用了哪些比喻？     |      |      |       |      | 参考答案文本…… | 答题思路   |

- **题型**：选择题 / 判断题 / 填空题 / 简答题。留空时系统会按内容自动判断。
- **答案**：选择题填 `A`/`B`/`C`/`D`（也可填"1"或选项原文）；判断题填 `正确`/`错误`；  
  填空题若有多个可接受答案，用竖线分隔：`一会儿|一瞬间|转眼间`。
- 判断题、填空题的选项列**留空**即可。

### 格式二：纯文本（手机上随手敲，适合微信复制粘贴）

```
# 观潮
@年级 四年级上册
@作者 周密
@简介 记叙钱塘江大潮的壮观景象。

[选择] 钱塘江大潮自古以来被称为？
A. 天下奇观
B. 世界奇景
C. 天下第一潮
D. 人间胜景
答案：A
解析：课文开篇总起句。

[判断] 潮来前江面上很平静。
答案：正确

[填空] 潮来时形成一堵两丈多高的（　）。
答案：水墙

[简答] 作者用了哪些比喻来写潮来时？
答案：把潮水比作白线、水墙……
```

规则：`#` 开头是课文名，`[选择]`/`[判断]`/`[填空]`/`[简答]` 或带"题"字的写法都认；  
`答案：`、`解析：` 分行书写。

### 格式三：JSON

即网站「导出题库备份」生成的格式，可原样导入，适合换电脑时迁移。

```json
{ "version": 1, "lessons": [ { "title": "观潮", "questions": [
  { "type": "choice", "stem": "题干", "options": ["A项","B项"],
    "answer": "A", "analysis": "解析" } ] } ] }
```

> **数据存在哪？** 全部保存在**访问者本机浏览器**的 localStorage 里，不上传服务器。  
> 这意味着：老师在自己电脑上传好题库后，换一台电脑或换一个浏览器打开是空的。  
> 所以请**务必定期「导出 Excel 题库」或「导出题库备份(JSON)」**，换设备时上传即可恢复。  
> 如果希望多人共享同一份题库，见文末「进阶」。

## 三·五、在网页里直接编辑题目（无需上传文件）

「题库管理」页点击任意课文的 **「管理题目」**，进入该课文的编辑器：

| 操作                 | 怎么做                      | 生效时机            |
| ------------------ | ------------------------ | --------------- |
| 改题干 / 选项 / 答案 / 解析 | 点题目上的「编辑」，改完「保存」         | 保存瞬间，首页与答题页同步更新 |
| 新增题目               | 「新增题目」→ 选题型 → 填写 → 保存    | 同上              |
| 删除题目               | 题目上的「删除」                 | 同上              |
| 调整题目顺序             | 题目上的 ↑ / ↓               | 同上              |
| 改课文信息              | 顶部「课文信息」表单（课文名/年级/作者/简介） | 点「保存课文信息」       |
| 新建课文               | 「题库管理」页「新建课文」            | 保存后出现在首页        |
| 删除课文               | 编辑器里「删除这篇课文」（有二次确认）      | 同上              |

**改了正在答的题怎么办？** 系统会自动同步：被改动题目的旧作答作废（避免按旧答案显示判分）、新增题自动排到题序末尾、删掉的题从答题会话中移除。你已删除的课文不会被任何操作"复活"，自己录入的题目也不会被内置示例覆盖。

**推荐工作流**：平时在网页里随手改 → 每隔一段时间「导出 Excel 题库」存档 → 下学期直接上传存档文件恢复。

## 三·六、课堂提问：学生名单 + 随机分题

给老师**点名提问**用的功能：先维护学生名单，上课时随机抽人或手动指定几名学生，选好课文和题型后，系统会给每位学生**随机分配不同的题目**。

页面入口：顶部导航「学生名单」（`#/roster`）和「课堂提问」（`#/ask` 设置 → `#/ask/run` 进行 → 小结）。

### 学生名单（`#/roster`）

- 支持**多个班级**：新建 / 重命名 / 删除班级，提问前选择班级即可
- 录入方式：逐个添加，或「批量粘贴名单」——支持从 Excel **整列复制粘贴**，也支持换行 / 逗号 / 顿号 / 空格分隔；同名学生自动跳过
- 支持单个改名、删除、清空本班名单，以及**导出名单**（CSV，一个名字一行）
- 每位学生自动累计「已提问 N 次 / 上次提问日期」，供「优先抽提问次数少的同学」使用

### 一次提问的完整流程

1. **选学生**（两种方式）
   - 随机抽取：填人数 → 点「随机抽取」（可勾选「优先抽提问次数少的同学」，让全班轮得更公平）
   - 手动指定：直接点名字多选
   - 抽完可继续手动增减；有「全选 / 清空」
2. **选范围**：课文可多选，题型可混搭（如只抽选择题 + 填空题），并设置「每位学生几道题」
3. **开始提问**：进入进行页，一次显示一位学生的一道题

### 随机分配的规则（`assignQuestions()`）

- 题库先整体洗牌再按顺序发放：**题库够用时，同学之间不会重题**（同一位学生内部也不会重复）
- 题库不够时自动开启第二轮循环使用，并提前弹窗提示，可在设置页看到「题目充足 / 题目不够」的实时提示
- 分配时会保存**题目快照**（题干 / 选项 / 答案 / 解析 + 课文名），所以提问过程中去改题库，不会打乱正在进行的这次提问

### 进行页（`#/ask/run`）

| 操作           | 说明                                                 |
| ------------ | -------------------------------------------------- |
| 显示答案         | 展开正确答案与解析（老师看，可随时收起）                               |
| 换一题          | 把当前题换成题库里还没用过的另一道题                                 |
| 临时加人         | 输入姓名即可加入本次提问：名单内同学沿用本人（提问次数照常累计），名单外同学标记「临时」、不写入名单 |
| 答对 / 答错 / 跳过 | 记录本题结果，自动跳到下一题；再点一次可取消重记                           |
| 上一位 / 下一位学生  | 也可以点页面底部的学生姓名直接跳转                                  |
| 正常 / 大字 / 投影 | 与答题页共用的三档投影字号                                      |

### 提问小结（结束提问后）

正确率圆环 + 逐人明细（每人分到哪些题、答对几道）+ 打印；「再抽一轮」会用同一批学生、同样的范围重新随机分题。有未记录的题时会提示「继续记录」，方便补记。

### 数据存在哪

仍然是浏览器本机 localStorage，新增三个键：

| 键                      | 内容                       |
| ---------------------- | ------------------------ |
| `yw_quiz_roster_v1`    | 班级与学生名单（含已提问次数）          |
| `yw_quiz_ask_v1`       | 正在进行 / 最近一次的提问（含题目快照与记录） |
| `yw_quiz_ask_draft_v1` | 提问设置页的选择（班级、课文、题型、题量…）   |

> **注意**：导出的 Excel / JSON 题库只含题目，**不含学生名单**。换电脑时请用名单页的「导出名单」带走名单，或在新的电脑上重新粘贴一次。

主要代码位置：`assets/js/app.js` 中的「学生名单」「课堂提问」两个段落（存储与逻辑）、`viewRoster / viewAsk / viewAskRun / viewAskSummary`（视图）、`bindRoster / bindAsk / bindAskRun`（交互）。

## 三·七、装到手机桌面（PWA，像 App 一样用）

网站本身就是一个 PWA（渐进式 Web 应用）：手机浏览器打开后可以**添加到主屏幕**，之后从桌面图标打开就是全屏、没有浏览器地址栏，和 App 的观感一致，而且**断网也能用**（题目本来就在本机）。

### 两种安装方式

| 手机                | 怎么装                                          |
| ----------------- | -------------------------------------------- |
| iPhone / iPad     | 必须用 **Safari** 打开 → 点底部「分享」按钮 → 「添加到主屏幕」→ 添加 |
| 安卓（Chrome / Edge） | 点右上角「⋮」→「安装应用」/「添加到主屏幕」                      |
| 微信里打开             | 先点右上角「···」→「在浏览器中打开」，再按上面操作                  |

网站页脚有「装到手机桌面」按钮，手机上首次打开还会在顶部出现一条提示，点「怎么装」会给出对应机型的步骤（iPhone 上会弹窗说明 Safari 的操作路径）。装好之后 `beforeinstallprompt` / `appinstalled` 事件也会被接住，安装成功会提示一句。

### ⚠️ 两个前置条件（很重要）

1. **必须用 https 访问**（或 `http://localhost`）。浏览器规定：用公网 IP 走 http、双击本地文件（`file://`）都不能启用离线缓存。此时网站照样能用，只是没有「离线打开」和部分机型的安装入口。  
   → 所以想用 PWA，就走 README 里的 **路线 A（备案域名 + COS/OSS）** 或 **路线 C（Cloudflare Pages / Vercel，自带 https）**，或在服务器上用 `certbot` 配一张免费证书。
2. **数据仍然只在本机**。装到桌面不会把题库搬到手机上——你在电脑上录的题，手机打开还是空的（见「七、进阶」的云同步说明）。手机端建议：用「导出名单 / 导出 Excel 题库」搬运一次，或用同一台设备备课。

### 更新与维护

- 改了 `index.html` / `assets/` 里的任何文件后，请把 **`service-worker.js` 里的 `CACHE_VERSION` 加 1**（例如 `v1` → `v2`）。老师下次联网打开时，新版本会在后台装好，页面顶部提示「网站已更新，刷新页面即可用上新版本」。
- 缓存策略：页面导航「先联网、失败再回落缓存」（保证拿到最新版），其它资源「先用缓存、后台更新」（保证秒开）。
- 如果发现手机上是旧版：先在**联网状态**下打开一次，然后完全关闭再打开；仍不行就卸载桌面图标重新添加。

## 三·八、U 盘便携模式（换电脑 / 带去教室）

老师的常见诉求：「在家里的电脑设计好题库和名单，带 U 盘去教室就能用」。做法是让数据跟着**网站文件夹**一起走：

1. 把整个网站文件夹拷到 U 盘（只需一次）
2. 在备课电脑上打开网站 →「题库管理 → **导出便携数据（U 盘用）**」→ 得到 `portable-data.js`
3. 把这个文件放进 U 盘里的网站文件夹（和 `index.html` 同一层，覆盖旧文件）
4. 到教室双击 U 盘里的 `index.html` → **自动读取**这份数据（题库 + 名单 + 成绩），无需任何导入操作
5. 在教室改过之后，再导出一次并覆盖 U 盘里的文件；回到家打开网站会提示「U 盘里的数据比本机新」，点「载入」即可

### 为什么是 `.js` 而不是 `.xlsx`

浏览器不允许网页（尤其是双击打开的 `file://` 页面）读取同目录的任意文件，但**允许加载同目录的脚本**。  
所以便携文件采用 `window.YW_PORTABLE_DATA = {...}` 的形式，双击打开也能自动加载；题库导出仍然是 Excel，两者互不影响。

实现要点（`assets/js/app.js` 的「便携数据文件（U 盘模式）」段落）：

| 行为        | 规则                                                                               |
| --------- | -------------------------------------------------------------------------------- |
| 加载        | `index.html` 里有一行 `<script src="portable-data.js"></script>`，文件不存在只是一次 404，不影响使用 |
| 首次在这台电脑打开 | localStorage 里还没有题库 → **自动载入**便携数据并写入本机                                          |
| 本机已有数据    | 便携文件比本机新（`savedAt` > `yw_quiz_local_saved_at`）才在顶部提示，由老师选「载入 U 盘数据 / 保持本机」       |
| 不再打扰      | 选「保持本机」会记下 `yw_quiz_portable_ignore`，同一份文件不再重复提示                                 |
| 导出        | 文件名固定 `portable-data.js`，方便直接覆盖；含题库 + 名单 + 成绩                                    |
| 写回 U 盘    | **需要手点一次**（浏览器不能自动往磁盘写文件），即「导出 + 拖进文件夹」两步                                        |

> 想要完全自动（网页直接读写 U 盘上的文件），只能改用「本地小服务」或桌面 App，见 `技术文档.md` 第七章末尾。

> ⚠️ **隐私提醒**：`portable-data.js` 里含学生真实姓名（整份名单），已在 `.gitignore` 里排除，
> **不要提交到公开仓库、不要发公开链接**；`package-zip.sh` 默认也不打它（需要连数据一起打包时加 `--with-data`）。

## 四、部署上线

### ⚠️ 先看这个：国内云对象存储的"强制下载"限制

这是选择腾讯云 COS / 阿里云 OSS 时**一定会踩的坑**，务必先读：

| 平台      | 限制                                                                          | 后果                           |
| ------- | --------------------------------------------------------------------------- | ---------------------------- |
| 腾讯云 COS | **2024-01-01 之后**创建的存储桶，用默认域名（含静态网站域名）访问**任意类型文件**都不支持预览                    | 打开网址直接下载 `index.html`，不是显示网页 |
| 阿里云 OSS | **2017-10-01 之后**创建的 Bucket，用默认域名访问 `.html` / `Content-Type: text/html` 的文件 | 同上                           |

官方给出的唯一解法是：**绑定自定义域名**。而国内节点绑定自定义域名需要该域名**已完成 ICP 备案**。

所以请根据自己的实际情况选路线：

| 你的情况              | 推荐路线                                       | 章节   |
| ----------------- | ------------------------------------------ | ---- |
| 已有（或愿意办理）备案域名     | 腾讯云 COS / 阿里云 OSS + 自定义域名                  | 路线 A |
| 没有备案域名，但要放在国内、要稳定 | 轻量应用服务器 + Nginx，用**公网 IP** 直接访问（IP 访问无需备案） | 路线 B |
| 没有备案域名，想最快上线、不折腾  | Cloudflare Pages / Vercel（免备案，国内多数地区可访问）   | 路线 C |

---

### 路线 A：腾讯云 COS + 自定义域名（最推荐，如有备案域名）

**A1. 创建存储桶**

1. 进入腾讯云控制台 → 对象存储 COS → 存储桶列表 → 创建存储桶
2. 名称：如 `yuwen-quiz-1250000000`（后缀是账号 APPID，系统自动补）
3. 地域：选离你学校近的，如 `广州 ap-guangzhou`
4. 访问权限：**公有读私有写**（一定要选这个，否则打不开）
5. 创建完成后进入桶 → 「基础配置 → 静态网站」→ 开启
   - 索引文档：`index.html`
   - 错误文档：`index.html`

**A2. 上传文件**

1. 「文件列表 → 上传文件」
2. 把 `index.html` 以及 `assets/`、`sample/` 整个目录拖进去（**保留目录结构**）
3. 上传完成后，文件列表里应当看到 `index.html`、`assets/css/style.css`、`assets/js/app.js`、`assets/js/data.js`

**A3. 绑定自定义域名**

1. 「域名与传输管理 → 自定义源站域名 → 添加域名」，填入你已备案的域名，如 `quiz.example.com`
2. 到域名解析处加一条 CNAME，指向腾讯云给出的 `xxx.cos.ap-guangzhou.myqcloud.com`
3. 在 COS 里为该域名**申请免费 SSL 证书**并开启 HTTPS

**A4. 验证**

浏览器打开 `https://quiz.example.com`，应当直接显示首页，而不是弹出下载框。

> **如果还是弹下载框**：说明自定义域名没生效，或文件元数据里 `Content-Disposition` 被设成了 `attachment`。  
> 到文件列表 → 该文件 → 「更多 → 修改元数据」，把 `Content-Disposition` 改为 `inline`，`Content-Type` 改为 `text/html`。

---

### 路线 B：轻量应用服务器 + Nginx（无备案域名时的国内方案）

用**公网 IP 访问无需备案**，这是最快能在国内跑起来的路子。

**B1. 购买与准备**

1. 腾讯云「轻量应用服务器」或阿里云「轻量应用服务器」，最低配（2 核 2G）足够
2. 镜像选 `Ubuntu 22.04`，放通防火墙 **80 端口**

**B2. 上传与配置**

```bash
# 1) 本地打包上传（在你自己的 Mac 上执行）
cd ~/WorkBuddy/教师网站
tar czf site.tar.gz index.html assets sample
scp site.tar.gz root@<服务器公网IP>:/tmp/

# 2) 登录服务器
ssh root@<服务器公网IP>

# 3) 安装 Nginx 并部署
apt update && apt install -y nginx
mkdir -p /var/www/quiz
tar xzf /tmp/site.tar.gz -C /var/www/quiz
chown -R www-data:www-data /var/www/quiz
```


**B3. 写入站点配置**

```bash
cat > /etc/nginx/sites-available/quiz <<'EOF'
server {
    listen 80 default_server;
    server_name _;
    root /var/www/quiz;
    index index.html;

    # 单页应用：找不到的路径回落到 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(css|js|png|jpg|svg|woff2)$ {
        expires 7d;
        add_header Cache-Control "public, max-age=604800";
    }

    gzip on;
    gzip_types text/css application/javascript text/html;
    gzip_min_length 1024;

    # 关键：不要给 html 加 attachment
    location = /index.html {
        add_header Content-Disposition "inline";
    }
}
EOF

ln -sf /etc/nginx/sites-available/quiz /etc/nginx/sites-enabled/quiz
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

**B4. 验证**

浏览器打开 `http://<服务器公网IP>`，应正常显示首页。

> 后期若办好备案，把域名解析到该 IP，再用 `certbot --nginx` 一键上 HTTPS 即可。

---

### 路线 C：Cloudflare Pages / Vercel（免备案，最省事）

适合"先给学生用起来"，国内大部分地区可正常访问。

**Cloudflare Pages**

1. 登录 `dash.cloudflare.com` → Workers & Pages → Create → Pages → Upload assets
2. 项目名随意，把 `教师网站` 文件夹里的**所有文件**拖进去（注意保留 `assets/` 目录层级）
3. 部署完成后会得到 `https://<项目名>.pages.dev` 这样一个网址，直接可用

**Vercel**

```bash
cd ~/WorkBuddy/教师网站
npx vercel --prod     # 首次会引导登录，一路回车即可
```

> 注意：这两个平台在国内的访问速度不如国内云，偶有波动。  
> 如果要给全校稳定使用，还是建议走路线 A。

## 六、更新与回滚

**更新内容**：重新上传 `index.html` / `assets/` 覆盖同名文件即可。  
线上页面是纯静态的，不会因为上传而丢失题库（题库在老师的浏览器里）。

**让用户拿到新版本**：静态文件默认会被浏览器和 CDN 缓存。若更新后学生仍看到旧页面，请他**强制刷新**（Mac `Cmd+Shift+R` / Windows `Ctrl+F5`）。

更彻底的做法是给资源加版本号，例如把  
`<link rel="stylesheet" href="assets/css/style.css">`  
改成  
`<link rel="stylesheet" href="assets/css/style.css?v=2">`  
每次更新递增 `v` 即可。

**回滚**：上传前把自己保留的上一版文件重新上传覆盖；或在 COS/OSS 控制台的「版本控制」功能里恢复到历史版本。

| ------------------------------- | ---------------------------------- | ------------- | ------- |
| 逻辑层 `tests/logic.test.js`       | Node `vm` 沙箱加载 `assets/js` 生产代码    | 29            | 约 0.1 秒 |
| 页面与路由 `tests/routes-check.html` | 无头 Chrome 逐个打开每个页面                 | 14 项检查        | 约 2 秒   |

## 七、进阶：让多人共享同一份题库

当前版本题库存在浏览器本地，**每位老师/每台电脑各有一份**。若要让全班同学访问同一个固定题库，有两种做法：

1. **零成本做法（当前即可用）**  
   老师在自己的电脑上配置好题库（网页编辑或上传 Excel 均可）→ 「导出 Excel 题库」或导出 JSON →  
   若用 Excel：把导出文件上传到任意一台课堂电脑的网页里即可（各机独立）；若要做成"所有访客默认加载"的内置题库：把导出的 JSON 写进 `assets/js/data.js` 的 `DEMO_BANK`，并把文件末尾的 `DEMO_SEED_VERSION` 加 1，重新上传。
2. **联网做法**  
   接入云数据库（用户登录 + 题库存云端 + 多人协作编辑）。学生名单同理：现在的名单也只在本机浏览器，若要多个老师共用一份名单、或把提问记录汇总到云端，也需要这一步。需要改造时说一声，可以在保留现有界面和交互的前提下加上。

## 八、常见问题

**Q：页面打开是白屏？**  
多半是 `assets/` 目录没上传或层级不对。F12 看 Console，若报 404 就补传对应文件。

**Q：点击"开始答题"没反应？**  
检查 URL 是否带上了 `#/`。地址栏应是 `https://你的域名/#/quiz/xxx`。若你的托管平台会拦截带 `#` 的路径，改用路线 B 的 Nginx `try_files` 配置。

**Q：导入 CSV 说"没有解析到任何题目"？**  
最常见原因是 Excel 存成了 GBK 编码。请重新「另存为 → **CSV UTF-8（逗号分隔）**」。其次是表头被改乱——建议直接用网站里的「下载 CSV 模板」。

**Q：选择题答案填了"A. 天下奇观"这种带选项文本的，能识别吗？**  
可以。系统会依次尝试：字母 → 带序号前缀的字母 → 数字序号 → 选项原文匹配。

**Q：能在课堂上投影用吗？**  
能。答题页右上角有字号切换按钮：正常 → 大字 → 投影，共三档，手机投屏到教室大屏时用「投影」档。

**Q：打印试卷/错题？**  
结果页有「打印结果」按钮，已做打印样式适配（会自动隐藏导航和按钮）。

**Q：提问时说"题目不够，会有重复"怎么办？**  
说明「选的课文 × 选的题型」范围内的题目数量，少于「学生人数 × 每人题数」。三个办法：多选几篇课文、把题型放宽（比如四种都选）、或者把每人题数调小。题库充足时页面上会显示绿色提示「题目充足，同学之间不会重题」。

**Q：抽人是怎么保证公平的？**  
每位学生都记录着「已提问次数」，勾选「优先抽提问次数少的同学」时，系统会只在**被提问次数最少的那批学生**里随机抽取，所以一学期下来全班机会比较均匀。学生名单页能看到每个人的次数。

**Q：学生名单存在哪？换电脑怎么带走？**  
和题库一样存在当前浏览器里（`yw_quiz_roster_v1`）。换电脑时：在学生名单页点「导出名单」下载 CSV，到新电脑打开网站 →「批量粘贴名单」把名字贴回去即可。注意「导出 Excel 题库」只含题目，不含名单。
